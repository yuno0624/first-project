# First Project

This demo shows a simple text area that automatically saves your input to `localStorage` and restores it when the page is loaded again.

## Features

- **Manual Save**: Press the **Save** button to store the current text.
- **Auto Restore**: When the page loads, any previously saved text is automatically restored.
- **Auto Save**: The current text is automatically saved when the page becomes hidden or before it unloads.

Open `index.html` in a browser to try it out.
